User Stories

Epic 1: Performance Monitoring
 
US-01 – View Channel Performance

As a YouTube creator,
I want to view my overall channel performance,
so that I can quickly understand how my content is performing.

Acceptance Criteria:
* Total videos are visible.
* Total views, likes, and comments are visible.
* Metrics update when filters are applied.

 US-02 – Track Subscriber Growth

As a creator,
I want to see subscriber gains from my videos,
so that I can identify content that contributes to channel growth.

Acceptance Criteria:

Subscriber gains can be analyzed at video level.
Videos can be compared based on subscriber gains.

 Epic 2: Content Analysis

 US-03 – Compare Categories

As a creator,
I want to compare different content categories,
so that I can understand which categories perform better.

Acceptance Criteria:

* Category-wise performance is available.
* Users can filter the dashboard by category.
* Performance metrics update after filtering.

 US-04 – Identify Top Videos

As a creator,
I want to identify my top-performing videos,
so that I can understand what successful content has in common.

Acceptance Criteria:

* Videos can be compared using performance metrics.
* High-performing videos can be identified.

 Epic 3: Publishing Strategy

 US-05 – Analyze Upload Timing

As a creator,
I want to analyze video performance by upload hour,
so that I can identify potentially better publishing times.

Acceptance Criteria:

* Upload-hour analysis is available.
* Users can filter by upload hour.
* Performance metrics update based on the selected hour.

 US-06 – Analyze Performance by Date

As a creator,
I want to filter performance by publish date,
so that I can analyze content performance over different periods.

Acceptance Criteria:

* Users can select a publish-date range.
* Dashboard visuals update according to the selected dates.

Epic 4: Decision Support

US-07 – Understand Engagement

As a creator,
I want to analyze engagement and retention metrics,
so that I can identify areas where my content can improve.

Acceptance Criteria:

* Engagement-related metrics are available.
* Retention can be analyzed alongside other performance indicators.

US-08 – Make Data-Driven Decisions

As a creator,
I want to identify meaningful performance patterns,
so that I can use them to plan future content.

Acceptance Criteria:

* Users can combine filters to explore patterns.
* Dashboard provides enough information to support content decisions.
