# Creator Insights – YouTube Creator Analytics Product

## 📌 Project Overview

Creator Insights is a self-initiated Product Management and Business Analytics project designed to help small and growing YouTube creators understand their content performance and make data-driven decisions.

## 🎯 Business Problem

Small creators often struggle to identify:

* Which videos perform best
* Which content categories generate more engagement
* Which videos drive subscriber growth
* Which upload times perform better
* Where audience retention is weak

## 💡 Proposed Solution

Creator Insights provides a centralized analytics dashboard that helps creators monitor important KPIs and identify content and publishing patterns.

## 👥 Target Users

* Small YouTube creators
* Growing creators
* Content managers
* Social media managers

## 🚀 MVP Features

* Channel performance overview
* Video performance comparison
* Category-wise analysis
* Upload-time analysis
* Engagement analysis
* Subscriber conversion analysis
* Top and bottom performing videos

## 📊 Key KPIs

* Views
* Watch Time
* CTR
* Audience Retention
* Engagement Rate
* Subscribers Gained
* Subscriber Conversion Rate
