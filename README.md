Creator Insights – YouTube Creator Analytics Product

Project Overview
Creator Insights is a self-initiated Product Management + Business Analytics project designed to help small and growing YouTube creators understand content performance and make data-driven decisions.
The project combines Product Management, SQL, Data Analysis and Power BI into one end-to-end analytics product.

Business Problem
Small creators often have access to large amounts of performance data but may struggle to turn that data into actionable decisions.

Key questions include:
* Which videos perform best?
* Which categories generate stronger engagement?
* Which videos contribute to subscriber growth?
* Which upload hours show better performance?
* Where is audience retention weaker?

Proposed Solution
Creator Insights provides a centralized analytics dashboard where creators can explore performance patterns using interactive filters and key performance indicators.

Workflow:
Dataset → SQL Analysis → Power BI Dashboard → Insights → Product Decisions

Power BI Dashboard
The dashboard provides an interactive view of YouTube creator performance.

 Dashboard Features
